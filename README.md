# Islamic Life - حياتك الإسلامية

تطبيق إسلامي عربي (Flutter) يعمل أوفلاين لأغلب المحتوى. مجاني بالكامل.

## المحتوى الحالي (المرحلة 1-2)
- المصحف كاملًا (114 سورة، 6236 آية) بالرسم العثماني، أجزاء، بحث، تفسير ميسر، ترجمة، تلاوة بعدة قراء مع سرعة وتكرار، علامات، متابعة القراءة، تتبع الحفظ واختبار.
- مواقيت الصلاة (حساب محلي، عدة طرق، العصر حنفي/جمهور)، القبلة، التقويم الهجري والمناسبات.
- الأذكار (الصباح والمساء + حصن المسلم) مع المصدر، عداد، مفضلة، مسبحة.

## المصادر
انظر شاشة "المصادر" داخل التطبيق: AlQuran Cloud (نص المصحف، التفسير الميسر، Saheeh International)، everyayah.com، Seen-Arabic/Morning-And-Evening-Adhkar-DB (MIT)، rn0x/hisn_almuslim_json (حصن المسلم - الترخيص غير محدد في المستودع)، adhan, hijri. خطوط: Amiri Quran و Cairo (OFL).

المحتوى الديني لم يُراجَع شرعيًا بعد من جهة علمية.

## البناء
`flutter pub get && flutter test && flutter build apk --release` أو عبر GitHub Actions.

## الحسابات
تسجيل الدخول اختياري عبر Firebase Auth (بريد وكلمة مرور) فقط. لا تُخزَّن أي بيانات أخرى على الخادم؛ التقدم والمفضلة محليان على الجهاز.
